# Netflix-Clone

## About

This repository contains a responsive Netflix Landing Page Clone developed using HTML and CSS. The project replicates the Netflix homepage interface while demonstrating responsive web design and modern front-end development concepts.

## Features

- Responsive Navigation Bar
- Hero Section
- Background Image with Overlay
- Email Subscription Form
- FAQ Section
- Responsive Layout

## Technologies Used

- HTML5
- CSS3
- Visual Studio Code
- Git
- GitHub
